How the Test Works

dynamic MCQ generation
  • 25 unique questions — one for each consonant in the table.
  • Random order — consonants are shuffled each time you take the test.
  • 3 Bangla tags per question — Place, Voicing, and Aspiration/Nasality.
  • 4 options — the correct letter plus 3 random distractors, shuffled.
  • Instant feedback — green for correct, red for incorrect; correct answer is always revealed.
  • End anytime — the "End Test" button stops the quiz and shows your full results.
  • Detailed review — see which questions you got right and wrong, with the correct answers.
